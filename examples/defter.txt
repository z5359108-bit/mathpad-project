7) Denklem çözümü  [soruyu çözen: algebra]
   Soru : 3*x + 4 = 10 denklemini çöz
   Sonuç: [{x: 2}]
   1. Denklemler
        3 x + 4 = 10
   2. Bilinmeyenli terimler bir tarafta, sabitler diğer tarafta
        3 x = 6
   3. Her iki tarafı 3'ye böl
        \frac{ 3 x }{ 3 } = \frac{ 6 }{ 3 }
   4. Kök
        x = 2
   5. Kontrol
        x = 2 \Rightarrow 10 = 10 \;\checkmark
   6. Çözüm kümesi
        {x: 2}

8) Denklem çözümü  [soruyu çözen: algebra]
   Soru : x^2 - 3x + 2 = 0
   Sonuç: [{x: 1}, {x: 2}]
   1. Denklemler
        x^{2} - 3 x + 2 = 0
   2. Standard biçim
        x^{2} - 3 x + 2 = 0
   3. Katsayılar
        a = 1, \quad b = -3, \quad c = 2
   4. Diskriminant formülü
        \Delta = b^2 - 4ac = -3^2 - 4 \cdot 1 \cdot 2 = 1
   5. Yorum
        \Delta > 0 \Rightarrow \text{iki farklı gerçek kök}
   6. Kök formülü
        x_{1,2} = \frac{-b \pm \sqrt{\Delta}}{2a} = \frac{3 \pm \sqrt{1}}{2} \Rightarrow x_1 = 2, \; x_2 = 1
   7. Çözüm kümesi
        [{x: 1}, {x: 2}]
