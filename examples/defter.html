8. Denklem çözümü

Soru: x^2 - 3x + 2 = 0
çözücü: algebra

Sonuç: $$\left[ \left\{ x : 1\right\}, \ \left\{ x : 2\right\}\right]$$

  1. Denklemler$$ x^{2} - 3 x + 2 = 0 $$
  2. Standard biçim$$ x^{2} - 3 x + 2 = 0 $$
  3. Katsayılar$$ a = 1, \quad b = -3, \quad c = 2 $$
  4. Diskriminant formülü$$ \Delta = b^2 - 4ac = \left(-3\right)^2 - 4 \cdot 1 \cdot 2 = 1 $$
  5. Yorum$$ \Delta > 0 \Rightarrow \text{iki farklı gerçek kök} $$
  6. Kök formülü$$ x_{1,2} = \frac{-b \pm \sqrt{\Delta}}{2a} = \frac{3 \pm \sqrt{1}}{2} \Rightarrow x_1 = 2, \; x_2 = 1 $$
  7. Çözüm kümesi$$ \left[ \left\{ x : 1\right\}, \ \left\{ x : 2\right\}\right] $$
