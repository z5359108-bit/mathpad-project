## 8. Denklem çözümü

> **Soru:** x^2 - 3x + 2 = 0  
> *(çözücü: `algebra`)*

**Sonuç:** $$\left[ \left\{ x : 1\right\}, \  \left\{ x : 2\right\}\right]$$

**Çözüm adımları:**

1. **Denklemler**

   $$
   x^{2} - 3 x + 2 = 0
   $$

2. **Standard biçim**

   $$
   x^{2} - 3 x + 2 = 0
   $$

3. **Diskriminant**

   $$
   \Delta = b^2 - 4ac = 1
   $$

4. **Yorum**

   $$
   \Delta > 0 \Rightarrow \text{iki farklı gerçek kök}
   $$

5. **Çözüm kümesi**

   $$
   \left[ \left\{ x : 1\right\}, \  \left\{ x : 2\right\}\right]
   $$
